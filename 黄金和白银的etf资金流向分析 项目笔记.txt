第三层：数据存储​
多数据库组合方案
推荐组合（成本最优）：


实时数据层：
  └─ Redis Streams (新闻/价格缓存，TTL 7 天)
  └─ TimescaleDB (中期数据，自动分区)
     └─ GLD/SLV 分钟级价格 (保留 1 年)
     └─ 新闻/情绪数据 (保留 2 年)
     └─ ETF 流量数据 (保留 3 年)

高频数据层：
  └─ InfluxDB (1 秒级 tick 数据，保留 30 天)
     └─ GC=F / SI=F 期货 tick 行情

冷存储层：
  └─ S3 / MinIO (历史存档，成本最低)

TimescaleDB vs InfluxDB 对比：​

选择 TimescaleDB：需要 ACID 事务、复杂查询、备份恢复

选择 InfluxDB：只关心写入速度、不需要事务、内存受限

Redis 在贵金属项目中的应用：
Redis 使用范例：

import redis
import json

r = redis.Redis(host='localhost', port=6379, decode_responses=True)

# 1. 缓存最新价格（Write-Behind 模式）
def cache_latest_price(symbol, price_data):
    # 写入 Redis
    r.hset(f"price:{symbol}", mapping=price_data)
    r.expire(f"price:{symbol}", 60)  # 1 分钟过期
    
    # 异步写入 PostgreSQL（通过 Kafka）
    producer.send('price-updates', value=price_data)

# 2. Redis Stream 存储新闻事件（保留 7 天历史）
def stream_news_event(news):
    r.xadd(
        f"news:stream:{news['symbol']}", 
        {'data': json.dumps(news), 'timestamp': news['timestamp']},
        maxlen=1000000  # 自动截断
    )

# 3. 消费 Stream（用于实时 WebSocket 推送）
def consume_news_stream(symbol):
    for msg in r.xread({f"news:stream:{symbol}": '0'}, count=50):
        yield json.loads(msg[1]['data'])
