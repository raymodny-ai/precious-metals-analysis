**问题**: 代码中直接实例化依赖，测试困难且违反SOLID原则

```python
# 使用FastAPI依赖注入
from fastapi import Depends

    return PriceFetcher()

def get_db_session() -> AsyncSession:
    async with async_session() as session:
        yield session

@app.get("/api/v1/prices/{symbol}")
async def get_price_data(
    symbol: str,
    fetcher: PriceFetcher = Depends(get_price_fetcher),
    db: AsyncSession = Depends(get_db_session)
):
    # 使用依赖注入的实例
    data = await fetcher.fetch_async(symbol)
    await db.execute(...)
```


### 3. **缺少数据持久化层**

**问题**: API直接调用fetcher实时获取数据，没有缓存和数据库存储

```python
# 当前流程：每次请求都重新抓取
API请求 → yfinance抓取 → 返回响应  # ❌ 慢且不可靠
```

**优化架构**:

```python
# 改进流程：定时任务 + 数据库 + 缓存
1. Airflow DAG → 定时抓取 → 存入PostgreSQL (TimescaleDB)
2. API请求 → 检查Redis缓存 → 命中返回 / 未命中查DB
3. 数据预聚合：日/周/月K线提前计算

# 示例实现
@app.get("/api/v1/prices/{symbol}")
async def get_price_data(
    symbol: str,
    redis: Redis = Depends(get_redis),
    db: AsyncSession = Depends(get_db_session)
):
    # 1. 尝试Redis缓存
    cache_key = f"prices:{symbol}:1d"
    cached = await redis.get(cache_key)
    if cached:
        return orjson.loads(cached)
    
    # 2. 查询数据库
    result = await db.execute(
        select(PriceData).where(PriceData.symbol == symbol)
    )
    data = result.scalars().all()
    
    # 3. 写入缓存
    await redis.setex(cache_key, 300, orjson.dumps(data))
    return data
```


## ⚠️ 性能优化

### 4. **同步阻塞调用**

**问题**: yfinance、requests等库是同步的，会阻塞事件循环

```python
# src/data_collection/price_fetcher.py
def fetch_price_data(self, symbol, start, end):
    ticker = yf.Ticker(symbol)  # ❌ 同步阻塞
    df = ticker.history(start=start, end=end)
```

**优化**:

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor

class AsyncPriceFetcher:
    def __init__(self):
        self.executor = ThreadPoolExecutor(max_workers=4)
    
    async def fetch_price_data(self, symbol: str):
        loop = asyncio.get_event_loop()
        # 在线程池中执行同步操作
        df = await loop.run_in_executor(
            self.executor,
            self._sync_fetch,
            symbol
        )
        return df
    
    def _sync_fetch(self, symbol):
        return yf.Ticker(symbol).history()
```


### 5. **批量请求未优化**

**问题**: 多标的查询串行执行

```python
# 低效实现
for symbol in symbols:
    data = fetcher.fetch(symbol)  # ❌ 串行，慢
```

**并发优化**:

```python
import asyncio

async def fetch_multiple_symbols(symbols: List[str]):
    tasks = [fetcher.fetch_async(s) for s in symbols]
    results = await asyncio.gather(*tasks, return_exceptions=True)
    return {sym: res for sym, res in zip(symbols, results)}
```

### 9. **输入验证不足**

```python
from pydantic import BaseModel, validator, Field

class PriceQuery(BaseModel):
    symbol: str = Field(..., regex="^[A-Z]{2,5}$")
    start_date: Optional[date]
    end_date: Optional[date]
    
    @validator('end_date')
    def validate_date_range(cls, v, values):
        if 'start_date' in values and v < values['start_date']:
            raise ValueError('end_date must be after start_date')
        return v
    
    @validator('symbol')
    def validate_symbol(cls, v):
        allowed = ['GLD', 'SLV', 'IAU', 'SIVR', 'AGQ']
        if v not in allowed:
            raise ValueError(f'Symbol must be one of {allowed}')
        return v
```

### 20. **外部API调用成本控制**

**问题**: DeepSeek/News API按量计费，未做成本控制

**优化策略**:

```python
class APIBudgetManager:
    def __init__(self, daily_budget: float = 10.0):
        self.daily_budget = daily_budget
        self.spent_today = 0.0
    
    async def check_budget(self, estimated_cost: float) -> bool:
        if self.spent_today + estimated_cost > self.daily_budget:
            logger.warning("api_budget_exceeded", spent=self.spent_today)
            return False
        return True
    
    async def record_usage(self, actual_cost: float):
        self.spent_today += actual_cost
        await redis.incrbyfloat("api_cost:today", actual_cost)
```
